
## Finovara

Backend platform for a personal finance management application, built with Java 25 and Spring Boot 4 as a set of microservices.


## About the Project

Finovara is a personal finance platform designed to help users take full control of their money. The backend exposes a secure REST API that powers tracking of income and expenses, budget management, savings goals, shared accounts and financial reporting.

The platform is built as a set of independent services, each responsible for a separate area of the domain, so that individual parts of the system can be developed, deployed and scaled on their own. Security is a central concern: authentication is based on JWT, sessions are tracked per device, and user activity is recorded in an audit log.

---

## Key Features

### Accounts and Security

- **Authentication and Authorization** - stateless JWT security built on Spring Security, with an access and refresh token flow.
- **Device and Session Tracking** - user-agent detection allows every session to be associated with a specific device, so users can see where their account is being used.
- **Security Monitoring** - tracking of sign-ins and sessions, and visibility of security-relevant events, helping users notice suspicious activity on their account.
- **Rate Limiting** - token-bucket based request throttling that protects the API from abuse and brute-force attempts.
- **Activity Log** - audit trail of user actions across the platform, giving a clear history of what happened and when.

### Personal Finance Management

- **Income and Expense Tracking** - full CRUD for financial operations with category tagging.
- **Shared Accounts** - multiple users can manage a common account, for example a household budget, with shared visibility of operations.
- **Virtual Wallet** - a personal digital wallet for day-to-day money management.
- **Savings Goals (Piggy Banks)** - define financial targets and track progress toward them over time.
- **Spending Limits** - budget control with configurable category-level limits and detection of reached thresholds.
- **Contracts Management** - tracking of user contracts and recurring financial obligations in one place.

### Insights and Communication

- **Statistics** - aggregated financial summaries and spending trends that show where money goes.
- **Reports** - generation of financial reports with PDF export.
- **Notifications** - notifications created in response to domain events, for example when a spending limit threshold is reached.
- **Email Delivery** - transactional emails sent through Spring Mail.

### Platform Capabilities

- **Scheduled Tasks** - distributed cron jobs with locking, so a job runs only once even when several instances of a service are deployed.
- **Event-Driven Processing** - side effects such as notifications and activity logging are handled asynchronously through Apache Kafka.
- **Caching** - Redis used to speed up frequently accessed data.
- **Database Versioning** - schema changes are tracked and applied with Liquibase migrations.
- **API Documentation** - interactive Swagger UI generated by SpringDoc OpenAPI.
- **Monitoring** - metrics collection with Prometheus and dashboards in Grafana.
- **Containerization** - the whole infrastructure is containerized with Docker and Docker Compose, with separate production and test database environments.

## Technology Stack

### Core

- **Java 25** - primary language of the project
- **Spring Boot 4** - application framework
- **Spring MVC** - REST controllers
- **Maven** - build and dependency management

### Security

- **Spring Security** - authentication and authorization
- **JWT** - stateless access and refresh tokens

### Data

- **Spring Data JPA** and **Hibernate** - persistence layer
- **PostgreSQL** - relational database
- **Liquibase** - database schema migrations
- **Redis** - caching

### Messaging and Integration

- **Apache Kafka** - asynchronous communication between services
- **Spring Cloud Gateway** - API Gateway
- **Spring Cloud OpenFeign** - declarative HTTP clients
- **Spring Mail** - email delivery

### Infrastructure and Observability

- **Docker** and **Docker Compose** - containerization and local infrastructure
- **Prometheus** - metrics collection
- **Grafana** - dashboards and visualization
- **SpringDoc OpenAPI** - API documentation with Swagger UI
